## About CanvasSmith

CanvasSmith is a web application for needlepoint designers who want to develop stitch-painted artwork in a focused digital workspace. It brings needlepoint design and thread organization together so project planning can remain connected to the visual design process.

The tool is intended for makers, artists, and designers working with needlepoint concepts that benefit from a structured digital workflow. Its emphasis on professional stitch-painted design makes it suitable for turning creative ideas into organized needlepoint projects.
